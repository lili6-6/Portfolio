# 《疯狂派对：不眠之夜》作品集项目文档

> 作品集用途项目介绍，突出程序侧技术设计能力与可扩展架构。

## 项目定位

《疯狂派对：不眠之夜》（Party Hard: Alternate Night）是一款**俯视角潜行暗杀策略游戏**。玩家扮演被辞退的社畜"莱姆"，戴上白面具潜入夜店，在限定时间内利用人群盲区、陷阱与道具暗杀目标，并规避目击、对抗警察，完成肃清任务。

## 基础信息

- 引擎：Unity 6（6000.4.12f1）+ URP 通用渲染管线
- 团队：5 人，我担任唯一程序员（程序 ×1 / 美术动画 ×4）
- 完整流程：主菜单 → 过场 CG → 关卡选择 → 夜店关卡 → 结算

## 核心玩法

- **近战处决**：拾取裁纸刀后，前方扇形目标一键击杀
- **藏尸灭迹**：搬运尸体投入藏尸点，防止尸体被目击而报警
- **环境击杀**：利用炸弹、毒药、吊灯、纵火等 11 种机关完成"看不见的谋杀"
- **道具合成**：4 格背包自由组合，如鸡尾酒 + 油箱可合成燃烧瓶
- **压力对抗**：NPC 目击报警 → 警察到场追捕、医生到场收尸
- **任务驱动**：完成击杀目标获胜，被警察抓捕则失败

## 技术要点

### 1. NPC 群体 AI（行为链状态机）

基于 TopDown Engine AIBrain 构建 9+ 个行为状态（游荡 / 跳舞 / 发呆 / 拥抱 / 进食 / 睡觉 + 恐惧路由），所有状态共享同一条优先级决策链。利用 `FalseState=""` 的 fall-through 机制实现"检测失败自动落到下一级"，整个决策逻辑无需手写 if-else，状态与分支的增删完全可视化配置。

### 2. NPC 性格系统（数据驱动，天然可扩展）

`NPC_Data`（ScriptableObject）集中定义行为权重、触发概率与时长区间；`NPC_PersonalityGenerator` 在生成时对权重叠加随机方差并归一化，将概率自动写入决策组件。**新增一种人格只需新建一个 SO 资产**，无需改动任何代码，即可让每个 NPC 行为个性各异。

### 3. 目击 → 报警 → 调度完整链路

扇形视野 + 视线遮挡检测发现尸体后，按"识破概率"判定目击到凶手还是尸体。报警自动分两条路径：警察已在场则直接上报目标；否则 NPC 跑向电话召唤新警车。警车沿路径到场、警察下车、追捕、逮捕、搬尸、撤离形成完整闭环；救护车按现场尸体数量动态配置医生，超时自动返场。

### 4. NPC 灵性系统

静态事件广播实现恐慌级联传染：燃烧、火灾、警察到场等异常源触发恐慌，按概率、冷却与 2 跳上限向周围扩散。渐进怀疑值让 NPC 注视尸体时累积怀疑、无异常时衰减，达到阈值才判定行为；好奇心则让 NPC 首次发现尸体时走近检查，丰富场景叙事感。

### 5. 自研 URP 渲染特性（ColorZone）

自定义 `ScriptableRendererFeature` + RenderGraph 全屏 Pass + 自研 Shader，实现"世界空间指定区域外灰度化、区域内保留彩色"的聚光式美术表现。Pass 仅对主相机生效，并通过 C# 侧计算逆 VP 矩阵传入 Shader，避免破坏后续 UI / Overlay 渲染。

### 6. 火焰燃烧链路

油箱倒油持续生成油坑 → 火焰点燃油坑触发连锁燃烧 → FireZone 灼烧角色 3 秒致死；燃烧瓶支持慢动作瞄准 + 抛物线轨迹预览后投掷，落地生成火焰区域。

### 7. 可扩展的机关框架

`Mechanism_Base` 统一抽象了触发、高亮、Party Vision、目标过滤、类型提示等全部通用能力，11 种机关（门 / 炸弹 / 毒药 / 藏尸 / 电话 / 传送等）自动注册到 `MechanismManager`。**新增机关只需继承基类、实现激活逻辑并挂载 Prefab**，即可自动获得全部通用交互能力。

### 8. 可扩展的道具框架

`Prop_Base` 抽象出拾取、选择、使用、合成、持续使用、消耗等完整生命周期接口，4 格背包与合成系统由 `PropManager` / `PropCombinationManager` 统一管理。**新增道具只需继承基类实现对应钩子**，即可接入拾取、槽位、合成与 UI，与既有道具无缝组合。

### 9. 流程与 UI

全局单例与场景管理器分层解耦，统一状态机驱动主菜单、过场、关卡、结算全流程；后处理由 VolumeManager 集中调度（暂停 / 受伤 / 胜利 / 失败 / 警察到场等 7 套效果）；HUD 完整覆盖任务列表、倒计时、连杀、道具栏等实时信息。
